# Stark visual assets

Add the required Stark animation files to this folder:

- `idle.gif`
- `running-right.gif`
- `running-left.gif`
- `waving.gif`
- `jumping.gif`
- `failed.gif`
- `waiting.gif`
- `working.gif`
- `review.gif`
- `spritesheet.png`

The application already consumes these names. Until the files are present, Stark uses the built-in vector mascot fallback so no broken image is shown.

`working.gif` should show Stark with an original technological armor in graphite gray, silver, metallic blue, and cyan luminous details.
